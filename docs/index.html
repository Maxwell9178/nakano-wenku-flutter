FEATURES

它替你做的事，只有「读书」

功能都围绕本地阅读展开，绝不越界到你没有允许的地方。

完全离线

正文、封面、进度、摘抄、书签全部保存在本机，断网也能安静读到最后一页。

多格式导入

EPUB 优先，兼容 TXT / DOCX / MD / ZIP 与 CBX 漫画包，多卷可自动分卷或合并。

3D 环形书架

13° 倾斜、惯性滑动、无限循环的立体书列，像在真正的书架上挑选今晚想读的那本。

液态毛玻璃

面板模糊与透明度可连续调节，深浅双主题、七种装饰配色，界面像玻璃一样透亮。

阅读记录

累计时长、打卡日历、兴趣雷达，安静地记录你读过什么，而不是催你多读。

一键备份

一个 .wkarchive 文件带走全部书架、进度与设置，换机只需一次导入。

ABOUT

一个初中生写的阅读器

没有团队，没有融资，只有课余时间和一台笔记本。

NakanoWenku 由 Maxwell 独立设计与开发，用 Dart 与 Flutter 编写，目前仅支持 Android。 它诞生于一个很朴素的念头：市面上的阅读器要么绑定书源、要么把数据放到云端， 而我只想要一个「把文件放进去，就能安静读完」的工具。

所以它完全离线、不需要账号、不申请多余权限，数据永远留在你自己的设备上。 代码全部开源，你可以自己编译，也可以直接看它到底做了什么。
